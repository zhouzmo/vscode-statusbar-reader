# 状态栏小说阅读器

在 VS Code **右下角状态栏直接显示**本地 TXT / EPUB 的正文。可选悬停阅读模式，自动翻页默认关闭。

## 安装与开始阅读

1. 在 VS Code 扩展视图中点击右上角 `…` → **从 VSIX 安装…**，选择本目录中的 `statusbar-novel-reader-0.1.10.vsix`。已安装旧版时安装此包升级，按提示重新加载窗口。
2. 按 `Ctrl+Shift+P`，执行 **状态栏小说: 打开 TXT / EPUB**，选择书籍。
3. 右下角状态栏直接显示当前段落，打开书籍后自动进入阅读状态。按 `1` 上一段，按 `2` 下一段。
4. 点击正文只进入阅读状态，不翻页。省略号打开阅读菜单，可修改翻页快捷键。状态栏没有上一段或播放 / 暂停图标。

升级后如仍只显示图标或阅读器被隐藏，在命令面板执行 **状态栏小说: 在右下角显示正文**。此命令关闭悬停模式、恢复阅读器并切换到右侧；未打开书籍时会提示选择文件。

要把右下角原有的行列号、缩进、编码、行尾、语言模式或 Prettier 等内容腾出来，**右键状态栏**，取消勾选相应项目，保留本插件的“小说：…”项目。插件只管理自己创建的项目，不改动其他插件的项目。右侧宽度不足时可减少每段字符数，或继续隐藏不需要的项目。

支持 VS Code 桌面版 1.85 及以上。插件优先运行在本地 UI 扩展宿主，在 WSL / SSH 窗口中也保留这个偏好；文件是否可选取、远程 URI 是否可读取决于 VS Code 的文件系统提供者。Windows / Linux 和远程窗口尚待实测。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 上一段 | `1`（阅读状态下） |
| 下一段 | `2`（阅读状态下） |
| 切换阅读 / 非阅读模式 | `Alt+R` |
| 阅读菜单 | `Alt+Shift+M` |

阅读状态指焦点位于状态栏。点击编辑器或输入框后，数字键用于正常输入；不会因为小说仍显示在状态栏而吞掉代码或聊天中的 `1`、`2`。

**切换到非阅读模式即隐藏内容，不绑定 `Esc`。** `Alt+R` 在阅读 / 非阅读模式之间切换：非阅读模式隐藏正文与阅读菜单、暂停自动翻页、保存当前位置；切回阅读模式恢复正文和进度。也可从命令面板执行“状态栏小说: 进入阅读状态”。

切换文本编辑器、用鼠标或键盘改变编辑器选区、修改当前文档、切换活动终端或窗口失焦时，会自动隐藏内容，并保留用户刚切换到的位置和输入焦点。启动时恢复书籍与进度，正文保持隐藏，直到主动进入阅读模式。

VS Code 没有通用的工作台焦点变化事件，因此**点击同一光标位置、重新聚焦同一个终端或点击第三方聊天输入框，不能保证立即自动隐藏**。这些场景下，数字键仍按焦点条件用于正常输入；需要立即隐藏时可使用阅读 / 非阅读模式开关。

在阅读菜单中选择 **配置翻页快捷键**，或执行同名命令，打开 VS Code 快捷键编辑器。修改“上一段”“下一段”绑定即可，不需要改插件源码。默认条件为 `statusbarNovel.visible && statusBarFocused && !inputFocus`，建议保留该条件，避免影响正常输入。使用自定义按键后，提示框内的 `1` / `2` 说明仍表示默认绑定。

## 切换书籍

按 `Alt+Shift+M` 打开阅读菜单，选择 **切换书籍**；也可在命令面板执行 **状态栏小说: 切换书籍**。列表按最近阅读排序，显示书名、进度和文件路径，可搜索路径区分同名书；首项可打开其他 TXT / EPUB。

切换前立即保存当前书的位置，选择另一书后继续它上次的阅读位置；切回原书或重新启动 VS Code 也能恢复。取消选择或目标书加载失败时保留当前书及其进度。切换时暂停自动翻页，选中当前书则重新进入阅读状态。

0.1.8 沿用原有的进度存储键，兼容旧版记录，并取消最多 30 本的进度淘汰限制。旧记录的书名和百分比在重新打开该书后补齐；升级前已被旧版淘汰的记录无法恢复。

0.1.9 支持从插件自身 `globalStorageUri` 下的 `library-update.json` 一次性导入书籍和合并重复路径。此文件格式为 `{"version":1,"additions":[{"uri":"文件 URI","title":"书名","totalLength":100}],"redirects":[{"from":"重复 URI","to":"保留 URI"}]}`。新书从开头开始，已有书籍不重置；合并时保留较大的字符偏移，并同步最近阅读路径。通过 VS Code 保存成功后才删除更新文件，保存失败则保留文件以便下次启动重试。书籍正文独立存放，不打入插件安装包。

## 章节目录与跳转

按 `Alt+Shift+M` 打开阅读菜单，选择 **章节目录**；也可在命令面板执行 **状态栏小说: 章节目录**，或点击正文悬停提示中的“目录”。目录按正文顺序显示，标记当前章节和各章在书中的百分比位置，打开时自动定位到当前章节。输入章节序号、课号（如 `03`）或标题关键词即可过滤，回车跳转并恢复状态栏的翻页焦点，继续按 `1` / `2` 阅读。

- **TXT：**自动识别独立成行、不超过 100 个 UTF-16 单元的标题，如“第一章 起点”“第十二节：继续”“Chapter IV: A new day”“Lesson 03: Please send me a card”。`NCE2.txt` 的 `Lesson 01` 至 `Lesson 96` 可生成课程目录。TXT 没有标准目录格式，正文中符合规则的短行也可能被识别；无明确标题时仍可使用原有段号跳转。
- **EPUB：**优先读取 EPUB 3 导航目录，再尝试 EPUB 2 NCX，支持同一正文文件内的章节锚点。忽略外部链接、隐藏内容、未纳入正文顺序的文件和失效锚点；无可用目录时从正文标题或正文文件边界生成目录。
- 阅读菜单和命令面板新增 **上一章 / 下一章**。前言位置执行“下一章”进入第一章；没有更前或更后的章节时保持当前位置。
- 打开目录会暂停自动翻页；取消目录不改变阅读位置。只在确认后跳转并立即请求保存进度。切换书籍、退出阅读或窗口失焦会关闭目录，旧目录不会修改新书的位置。
- 目录基于内存中的最终正文建立，不改写书籍或正文、不改变原有 `readingState.v1` 进度格式。每次打开书籍重新生成目录，修改每段字数后仍按章节字符位置定位。EPUB 行内锚点跳转到包含该锚点的段落。

## 显示与翻页设置

在设置中搜索 `statusbarNovel`，或在阅读菜单中执行“切换悬停阅读”。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| `statusbarNovel.alignment` | `right` | 在右下角显示，可选 `left` 切回左侧 |
| `statusbarNovel.hoverOnly` | `false` | 开启：只显示书本图标，悬停提示框显示正文；关闭：正文直接显示在状态栏 |
| `statusbarNovel.charactersPerPage` | `28` | 每段最多 12–100 个字符，尽量按标点和换行断开 |
| `statusbarNovel.showProgress` | `false` | 直接显示模式下附加当前段号 / 总段数 |
| `statusbarNovel.autoPageSeconds` | `6` | 自动翻页间隔，范围 1–120 秒 |
| `statusbarNovel.encoding` | `auto` | TXT 的自动或指定编码，重新打开文件后生效 |

**鼠标交互边界：**原生 `StatusBarItem` 没有鼠标进入、离开和滚轮事件。此插件用官方悬停提示框实现悬停阅读，正文显示在提示框中；出现和消失延迟由 VS Code 控制，指针移入提示框时仍可阅读或点击链接。它不能实现状态栏文字本身随鼠标进入 / 离开立刻切换，也不支持滚轮翻页。翻页后提示框的刷新或收起行为同样由 VS Code 控制，必要时移开再悬停。

如不希望阅读状态出现焦点边框，可在当前工作区的 `workbench.colorCustomizations` 中把 `statusBar.focusBorder`、`statusBarItem.focusBorder` 设为 `#00000000`。这只影响状态栏焦点边框，阅读器仍保留键盘焦点。原生插件接口也不能控制其他插件或内置状态项的显隐，本插件不提供进入 / 退出阅读时自动隐藏、恢复它们的功能。

自动翻页默认关闭，状态栏不显示播放 / 暂停图标。需要时按 `Alt+Shift+M` 打开阅读菜单，选择“开始自动翻页”或“暂停自动翻页”。此功能仅在关闭悬停阅读后可用；隐藏阅读器、切换书籍、修改设置、到达末尾或 VS Code 窗口失焦时暂停，恢复窗口或重启后需手动开启。

## 格式支持与数据保存

- **TXT：**支持 UTF-8、带 BOM 的 UTF-16 和 GB18030（兼容 GBK）。自动检测可能误判，无 BOM 的 UTF-16 或乱码文件可指定编码后重新打开。
- **EPUB 2 / 3 文字书：**根据 `META-INF/container.xml` 定位 OPF，再按 `spine` 顺序读取正文，解码 HTML 实体并去掉标签、脚本、样式和导航。导航另外解析为可跳转的章节目录，正文中的标题保留，章节之间分段。跳过标记为 `linear="no"` 的附加内容。
- 不渲染排版、图片、音视频，不支持 DRM 加密书、纯图片书，以及 SVG 正文或复杂自定义实体。
- 输入文件上限 64 MiB；TXT 上限 16 MiB；EPUB 每个解压文本文件上限 16 MiB、累计上限 32 MiB，合并正文上限 16 Mi 个 UTF-16 单元。较大 EPUB 首次解析可能短暂占用扩展宿主。
- 不修改书籍、不上传正文、不请求远程书籍资源。正文只保存在内存中，进度写入 VS Code 的插件 `globalState`，键为 `readingState.v1`，包括最近书籍 URI、隐藏状态，以及每本书的字符偏移、书名、正文长度和更新时间。所有书籍的进度均保留，此插件未启用这些数据的设置同步。
- 进度按文件 URI 区分，换文件名或移动书籍后视为另一本书；原书内容变化后偏移可能发生偏差。修改每段字符数会尽量保留当前位置。

## 开发与验证

源代码使用 CommonJS JavaScript，无须 npm install 或编译。以单独窗口打开本目录，按 F5 使用 `.vscode/launch.json` 启动扩展开发宿主。

核心调用链：命令 / 状态栏点击 → `src/extension.js` → `src/book.js` 解析与分页 → 状态栏显示；进度通过 `ExtensionContext.globalState` 保存。

打包脚本只把源码和随附依赖写入 VSIX，不启动 VS Code、插件或工程构建：

```bash
/usr/bin/python3 scripts/package.py
```

可由使用者执行解析测试（Node.js 18+）：

```bash
node --test tests/*.test.js
```

解析测试包含 TXT 标题识别、正文归一化后的章节偏移、重新分页、EPUB 3 导航锚点、EPUB 2 NCX、重复目录项和失效目录降级。模拟 VS Code 接口的交互测试覆盖当前章节定位、确认与取消、切书进度、章节边界和失焦期间的旧选择失效；仍需实际 UI 验证焦点和搜索行为。

建议在扩展开发宿主或安装 VSIX 后检查：UTF-8 / GBK TXT；EPUB 章节顺序和实体；NCE2 目录的 96 课及课号搜索；当前章节定位；确认跳转后按 `1` / `2` 翻页；取消目录不改位置；上一章 / 下一章及首尾边界；目录打开期间切书或窗口失焦；修改每段字数后再跳转；切书后重启的进度；点击正文不翻页；回到编辑器后数字正常输入；自定义翻页键；右下角正文显示与左侧位置切换；悬停阅读与直接显示切换；隐藏后执行“在右下角显示正文”；自动翻页及窗口失焦暂停。静态检查不能替代这些 UI 验证。

随附依赖：`fflate` 用于 ZIP 解压，`sax` 用于 XML 解析。固定版本、来源和下载完整性记录见 `vendor/packages.json`，许可证见对应的 `vendor/*-LICENSE`。
